## Added

- `cratis render` and `cratis render --check` receipts list, for every path, the semantic declarations the file realizes (`sources`: id, kind and a readable `Module/Feature/Slice/Name` address), plus a `bySource` view that maps each declaration to its files; scaffold files have no sources. The receipt schema version is now `2` (#246)

## Changed

- The ownership manifest `.cratis-render.json` stores the semantic ids of each managed file and uses schema `2`. A destination rendered by an earlier CLI is upgraded on its next render (`--check` reports that one manifest rewrite with exit `6`), and an earlier CLI refuses to publish over a schema `2` destination. Generated files are unchanged (#246)
