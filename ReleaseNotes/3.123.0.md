The CLI now bundles Screenplay 5.11.0 and Stage 4.226.0, so `cratis` reads models that declare development users with `user`, and `cratis run` starts the Stage that offers them to Lens.

## Changed

- The CLI bundles Screenplay 5.11.0, which adds `user <name> ["<display name>"] [as <Persona>, ...]` for the people a development or test session acts as, and Stage 4.226.0. `cratis run` uses the `cratis/stage:4.226.0` image by default.
- With Stage 4.226.0, a sandbox started with `Stage__Sandbox__Users=true` lists the model's users at `/.cratis/users` for Lens. It is off unless set, and Stage refuses to start with it outside development.
