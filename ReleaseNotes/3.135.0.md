## Summary

`cratis run` can now leave a Stage sandbox running in the background once it is ready, and the new `cratis stop` command stops it again, so scripts and agents can start a Screenplay model, probe it and shut it down without holding a terminal open.

## Added

- `cratis run --detach` waits until the Stage is ready, prints its addresses and container name, and exits with the sandbox left running; if startup fails or is cancelled, the container is removed again (#566)
- `cratis run --timeout <seconds>` sets how long the command waits for the Stage to become ready before stopping it; detached runs default to 300 seconds, foreground runs wait until you stop them (#566)
- `cratis stop` stops a sandbox started by `cratis run`, by name or with `--all`, and reports Not found when the named sandbox is not running (#566)
