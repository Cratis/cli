## Added
- A spec that plans a folder where a module imports a feature that imports a slice. It fails without the fix.

## Fixed
- `cratis render` on a folder composed through `import` no longer reports `PLAY0001` ("Unexpected 'feature' at the top level") for every imported feature and slice file. The scene compile resolved an import's folder through a file listing that ignored the folder it was asked for, so nested imports never found their targets. The listing now reports files relative to the folder requested, as a disk does.
