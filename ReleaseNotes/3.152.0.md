`cratis affected` can split a merge-time run across jobs, one per test project.

## Added

- Add `cratis affected projects`, which lists the test projects of a repository as `.cratis/affected.json` sees them (part of Cratis/Workflows#268).
- Add `--projects` to `cratis affected run`, which builds the coverage maps of only the named test projects in a merge run and leaves the maps of the others alone.
