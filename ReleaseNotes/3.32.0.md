## Added

- `cratis screenplay validate --executable` also binds the model into an executable semantic model and fails with its binding diagnostics, such as `PLAY0268` for event sources and streams, when it does not bind. It never renders, writes files or needs a container runtime, and its JSON summary reports `executable`. A document a root file imports from above its folder reports `CLI-VALIDATE-001`, and a document the binder cannot represent reports `CLI-VALIDATE-002`. (#243)

## Changed

- `cratis screenplay validate` states which verdict it checked: the JSON summary reports `checked` (`source` or `executable`), and the text summary says that a plain pass checks the source only. The Screenplay reference explains the difference between a valid, an executable and a renderable model.
