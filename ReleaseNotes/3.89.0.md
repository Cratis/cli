## Added

- `cratis new` uses the Cratis templates installed under `~/.cratis/templates`: the first run downloads the latest set from NuGet, `--version` still picks another version for a single run, and without network access an already downloaded set is used. See [Template catalogue](https://github.com/Cratis/cli/blob/main/Documentation/new/templates.md). (#164)
- `cratis update` also installs newer Cratis templates when they work with the installed CLI, never downgrading and never failing the update when templates cannot be refreshed; `--no-templates` skips the check. (#164)

## Fixed

- `cratis update` shows the release notes after the CLI, template and Stage results, and builds include the notes of 3.87.0 and 3.88.0, which those releases did not keep. (part of #153)
