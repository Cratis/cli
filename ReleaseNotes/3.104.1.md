## Changed

- When `cratis render` or `cratis run` refuses a `ui profile` because it uses a published Scene domain blueprint that has not been approved (`CLI-RENDER-007` or `CLI-RENDER-020`), the message now names the Scene package that publishes it, for example `@cratis/scene.blueprint.invoicing` for `Cratis.Blueprint.Invoicing`, and links to the steps for approving it. The new [Use a published Scene blueprint](https://github.com/Cratis/cli/blob/main/Documentation/reference/screenplay.md#use-a-published-scene-blueprint) section gives those steps: install the package, write the approved package set with one `node` command, and pass it with `--package-set`. (#483)
