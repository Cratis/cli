## Added

- `cratis render --migrate-reducer <ReadModel>` migrates a read model built by a classic reducer to a self-reducing read model that keeps the existing Chronicle observer. The option takes `Module.Feature.Slice.ReadModel` or the read model's semantic id and can be repeated. The old reducer file is removed in the same publication as the new files, and an interrupted publication restores it. See [Migrate a classic reducer](https://github.com/Cratis/cli/blob/main/Documentation/reference/screenplay.md). (#415)
- `CLI-RENDER-025` refuses a publication when a file it must remove changed since planning or Stage reports the removal as unsafe; nothing is written or deleted. `CLI-RENDER-026` refuses a migration request that cannot be honored (unknown read model, no or several classic reducers, an edited reducer file, or combined with `--scope`). Both exit with 5. (#415)

## Changed

- The bundled Stage is 4.178.2, so `cratis run` and `cratis render` default to the Stage 4.178.2 container. After migrating a destination, upgrade every CLI that renders it: older CLIs refuse to render a migrated destination with `CLI-RENDER-021`. (#415)
