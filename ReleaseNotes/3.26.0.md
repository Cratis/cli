`cratis screenplay mcp` now starts the Screenplay MCP server without a fixed model folder when the project has no Screenplay configuration, and the embedded server is updated to Screenplay 4.59.0.

## Added

- Without a path or `.cratis/ai.json`, `cratis screenplay mcp` lets the server pick its workspace: the `path` given to `open-workspace`, then the single workspace root your MCP client offers, then the current directory when it already holds `.play` files. If none applies it asks for a path instead of guessing.

## Changed

- The embedded Screenplay compiler and MCP server are Screenplay 4.59.0: authoring readiness is reported separately from executable readiness, rejected proposals list their diagnostics, `apply` is no longer marked destructive, and the board follows the model on disk.
- Explicit paths, `--project-root`, `--project-root-env` and a configured `.cratis/ai.json` root behave as before.
- The managed AI corpus is refreshed to Cratis AI 7.6.5.
