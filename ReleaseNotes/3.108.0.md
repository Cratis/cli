`cratis render --target axon` now renders models it used to refuse or crash on in default mode, and `--strict` applies to Axon.

## Changed

- `--strict` now reaches the Axon renderer: renderer errors block publication and degradation evidence returns exit `9`, instead of being ignored with a `CLI-RENDER-030` warning. Axon promotes its warnings to errors under `--strict`, so strict Axon renders of apps with warnings such as `STAGE-AXON-0308` now fail. (#489)
- In default mode, execution-plan issues that belong to individual slices (for example `PLAN-UNSUPPORTEDEVENTCONTEXT`) become `PLAN-*` warnings and the Axon render continues, instead of refusing the whole render. `--strict` and the Cratis target are unchanged. (#489)

## Fixed

- An unexpected Axon renderer exception no longer crashes `cratis render`; it reports `CLI-RENDER-031` with the renderer package version, the exception type and message and a link for reporting the bug, and publishes nothing. (#489)
