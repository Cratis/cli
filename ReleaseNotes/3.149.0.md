## Added

- `cratis chronicle check-release --release <file.json>` checks, before publishing, whether a client release fits the Chronicle kernel it will be deployed to. It reads the kernel version, checks that the client's contracts are served, and asks the kernel which event type registrations would be rejected, without writing anything. Output uses the shared `cratis.compat/v1` format with a verdict per check (`chronicle-kernel`, `chronicle-contracts`, `event-schemas`), and the command exits non-zero when the release is incompatible or compatibility cannot be determined. The documentation includes the input file, the output and a GitHub Actions example. (#602)
