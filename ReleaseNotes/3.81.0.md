## Changed

- Bundles Stage 4.154.1 and Screenplay 4.216.0; `cratis run` starts `cratis/stage:4.154.1` by default (#402)
- `cratis render` admits ESM v1 through v28: Uuid `==` and `!=` comparisons in `require` and `produces when` render; ESM v29 and later are refused with `CLI-RENDER-004` (#402)
- Resolved C# validation rule bodies now render into validators instead of being refused with `STAGE-ESM-005`; bodies that do not compile or read members Stage does not supply report `STAGE-ESM-019`, `STAGE-ESM-022` or `STAGE-ESM-015` (#402)
- The Stage Host defaults to the semantic engine and the `eventmodel` engine is deprecated; `cratis run --engine eventmodel` still works but Stage warns at startup (#402)
