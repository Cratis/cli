## Summary

`cratis render` now chooses which Stage scaffold profile to use: new Cratis applications are rendered on .NET 11, and existing applications keep the profile they were rendered with until you opt in to upgrade.

## Added

- `cratis render --upgrade-profile` moves an existing Cratis application to the newest scaffold profile (.NET 11) (#579)

## Changed

- New Cratis applications rendered with `cratis render` target .NET 11; existing applications keep their recorded profile and render unchanged (#579)
- Rendering uses Stage 5.11.0 and Screenplay 6.18.0 (#579)
- `cratis render` admits the Screenplay model versions Stage 5.11.0 supports, including the v34 models Screenplay 6 produces (#579)
