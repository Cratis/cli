## Added

- `cratis screenplay validate` and the embedded MCP server accept policy negation (`not role`, `not claim`, `not authenticated` and `not (...)`), which selects ESM v7, and warn with `PLAY0546` when `not` applies to a claim whose target can be absent or is not text. `cratis render` rejects such a model with the blocking `CLI-RENDER-004` diagnostic, because the bundled renderer does not render it yet. (#271)
- Screenplay models can declare `depends on` for modules and features, define reusable `example` values for specifications, give a screen `action` conditional alternatives, and route specification events with `stream`. `cratis screenplay validate` checks them; specification event routes and reaction `on refused`, `when redelivered` and `then no events` are not executable yet, so `cratis screenplay validate --executable` and `cratis render` report `PLAY0268` for them.
- The embedded MCP server's `diagnostics` tool takes `scope` (one module, feature or slice) and `checks` (opt-in completeness checks); `cratis screenplay validate` does not offer these yet. The server also adds a `semantic-diff` view to `read-proposal`, a dependency map on the event model board, dependency declarations in `dependency-graph` and `declaration-details`, routing data and effective example values with their origin in `find-fixtures`, examples in search, references and rename, routing data in `find-references` and `dependencies`, and opens other registered Git worktrees of the same repository.

## Changed

- The CLI bundles Screenplay 4.81.7 and Stage 4.30.0.
- `cratis screenplay validate` reports new diagnostics for `depends on`: `PLAY0554` and `PLAY0555` (warnings) for an invalid or repeated target, `PLAY0552` (warning) for a dependency the model uses but the container does not declare, and `PLAY0553` and `PLAY0556` (information) for an unused or mutual declaration. Warnings fail `--warnings-as-errors`.
- `cratis screenplay validate` and `cratis render` reject a personal-data value typed directly in a reaction trigger as a reaction destination (`PLAY0515`), report `PLAY0524` once per missing required fixture property and `PLAY0519` for a property assigned twice in a step, and resolve a reaction's `for` to the event when an event and an application trigger share a name.
- Printed models keep large integers and small fractions as written instead of in scientific notation.
- `cratis render` produces applications for Arc 22.50.5 and Chronicle 19.32.0, renders role-only and claim-only policies as Arc policies, and refuses a specification whose caller is not signed in but has roles or claims (`STAGE-ESM-011`).
- `cratis run` starts the Stage 4.30.0 container. It still compiles models with the container's own Screenplay release, which does not parse policy negation, `depends on`, `example`, conditional screen actions or specification event routes, so a model that uses them can pass `cratis screenplay validate` and still fail `cratis run`.
