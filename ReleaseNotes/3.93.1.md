## Changed

- The Screenplay MCP server and other Screenplay commands now use `<project>/Screenplay` as the model folder when `Source` or `src` holds no `.play` files or Screenplay state, instead of treating the application's source folder as the model. (#428)

## Fixed

- `prologue start` now prints an Extractor `docker run` command that mounts your captures folder into the container, so captures are no longer lost when the container exits, and publishes the OpenTelemetry ports 4317 and 4318 when you capture from OpenTelemetry. The command pins the Extractor image to the bundled Prologue version, and `cratis-prologue.json` keeps the captures folder you chose, so `prologue interpret` finds the captures without a path. (#426)
