## Added

- `cratis build` carries out Studio's removal orders (build contract 3): when a built slice is deleted, the CLI hands the removed slices' ids, former names and declaration names to the agent or generator, which removes the files it built for them and reports each removed file by its exact path; only those files are committed. The built-in Cratis builder levels and kits that opt in advertise contract 3; generators without a kit keep contracts 1 and 2 (#611)
