The CLI now bundles Screenplay 5.10.0 and Stage 4.225.1, so `cratis` reads and runs models that use graphs, graph queries and `foreach`, and `cratis run` starts the matching Stage image.

## Changed

- The CLI bundles Screenplay 5.10.0 (ESM v41) and Stage 4.225.1, and `cratis run` uses the `cratis/stage:4.225.1` image by default. Models can now declare graphs, read them with typed `match` queries and draw one edge per item with `foreach`.
- Applications rendered by `cratis render` pin Arc 22.168.0 and Chronicle 19.134.0. Own public events are written to a separate `<Project>.Events.Contracts` project, and guarded actions render as `core:guarded-action`.
- `cratis render` still admits models up to ESM v32, so a model that uses graphs is validated and run, not rendered.
- The CLI's own Chronicle client stays on 19.113.2: newer Chronicle releases need an administrator login to manage applications and users, which is tracked in #557.
