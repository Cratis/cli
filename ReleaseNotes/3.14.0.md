## Added

- `cratis run` accepts a single Screenplay (`.play`) file as well as a folder. Only that file is mounted, read-only, and handed to the Stage; the folder it sits in is not mounted (#128)

## Changed

- `cratis run` mounts a Screenplay folder read-only (#128)
- `cratis run` finds `.play` files in a folder in any casing on every platform (#128)
- `cratis run` rejects a missing path, a file without the `.play` extension, or a path containing a colon before Docker is started (#128)
