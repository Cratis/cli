The CLI now bundles Stage 6.2.2 and Screenplay 6.32.0, so `cratis render` and `cratis run` pick up the Stage 6 rendering fixes.

## Changed

- The CLI bundles Stage 6.2.2, built on Screenplay 6.32.0 and Scene 6.0.1, and `cratis run` uses the `cratis/stage:6.2.2` image by default. Reaction specifications that assert a refusal outcome, or whose reaction appends a constraint-target event, now render (#633)
- `cratis render --target cratis` generates applications on Arc 23.8.0 and Chronicle 19.162.0. Re-rendering an existing application moves it to Arc 23, so hand-written code beside the generated code may need updating for Arc 23
- Rendered applications follow Stage 6: profiles carry the resolved design system, and free screens no slice adopts are not rendered
- A model whose UI uses syntax Stage cannot convert is reported as a `cratis render` and `cratis run` diagnostic instead of stopping the command with an exception
