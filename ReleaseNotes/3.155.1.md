## Fixed

- `cratis chronicle observers retry-partition` and `clear-partition-quarantine` now work for operators who have only Manage access. When the CLI may not list observers, it uses the given or default event sequence and leaves the decision to the server. (#674)
- Failed-partition recovery finds the namespace when its letter case differs from the stored name. If the namespace cannot be checked, the command is sent and the server decides. If Chronicle reports an error while reading namespaces, the command stops with a server error and sends nothing. (#674)
