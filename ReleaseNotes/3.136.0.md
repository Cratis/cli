`cratis build connect` no longer needs the Studio's address when it is the hosted Studio.

## Added

- `cratis build connect --studio --organization <name>` connects to the hosted Studio, `https://app.cratis.studio`. Give `--studio <url>` only for another Studio.

## Changed

- `--studio` accepts the builder address `https://<studio host>/builders/connect/<organization>` and takes the organization from it, instead of failing with `405 MethodNotAllowed`.
- The documented examples now use the hosted Studio's address rather than `https://cratis.studio`.
