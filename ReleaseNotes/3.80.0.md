## Added

- `cratis chronicle streams closed list` lists the closed stream scopes of an event sequence with their dimensions, origin, owning constraint, sequence number and closing time, filtered by event source id or type and event stream type or id; table, plain and JSON output. Requires Chronicle 19.39.0 or later. (#304)
- `cratis chronicle streams closed reopen --reason <text>` repairs a mistaken manual close of one exact scope, after confirmation (`--yes` to skip); the kernel records the reason and actor as a `StreamScopeReopened` event and refuses closures owned by a closing event. (#304)
