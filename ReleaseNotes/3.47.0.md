## Added

- `cratis render` renders Screenplay ESM v8 models: event sources, streams, routed commands and routed specifications render through the bundled Stage 4.62.0. ESM v9 and v10 are still refused with `CLI-RENDER-004`, naming the version (#290)

## Changed

- The CLI uses Stage 4.62.0, and `cratis run` starts the matching `cratis/stage:4.62.0` container. That container's default engine refuses event sources, streams and routes with `STAGE-ESM-030`, so render routed models with `cratis render` (#290)
