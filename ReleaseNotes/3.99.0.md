## Added

- `cratis chronicle jobs delete <JOB_ID>` requests deletion of a retained job and its state. Before asking for confirmation it shows the event store, the namespace, the job ID and that deletion cannot be undone. `--yes` only skips the local prompt: the Chronicle server still decides whether the deletion is allowed. Success is reported as "deletion requested"; an invalid ID, a declined or unavailable confirmation, a server refusal, an authorization failure or a server error exits non-zero. (part of #199)
