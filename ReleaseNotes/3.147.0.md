## Changed

- `cratis render` renders a model whose compilation excludes slices or specifications, keeping the exclusion evidence in Stage output; the Axon target refuses such models until its renderer supports exclusions (#643)
- `cratis render` and `cratis run` use Stage 6.4.1 (#643)
- The Screenplay rendering reference names the exact Screenplay, Stage, Axon renderer, Arc and Critter Stack adapter versions bundled with the CLI, the package versions a rendered application gets, and that `cratis run --tag` only selects the Stage runtime image; a minimal render example shows the generated package manifest and the commands to build and run it (#641)
