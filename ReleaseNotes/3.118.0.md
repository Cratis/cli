Applications rendered and run from a model with onboarding now start new tenants on the model's offering and tell declined applicants why.

## Changed

- The CLI bundles Stage 4.212.0: `cratis render` renders a model's `offering` against Box Office and sends the `signupDeclined` email when Ante declines a reviewed sign-up, and `cratis run` uses the `cratis/stage:4.212.0` image by default
- `cratis run` starts `ghcr.io/cratis/ante:1.6.0` by default for models that declare onboarding, which supports reviewing sign-ups before they complete
