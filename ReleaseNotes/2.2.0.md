## Added

- `cratis llm` group — configure the language model used by Cratis tools: `use <anthropic|openai|local>` (interactive prompts, secret API-key input), `show` (masked key), and `clear`
- `cratis prologue start` — interactive wizard producing a `cratis-prologue.json` capture definition (SQL Server/PostgreSQL sources, API reverse-proxy capture, OpenTelemetry, JSON or Receiver API output)
- `cratis prologue interpret [PATH]` — interprets captured data into a Screenplay `.play` file, streaming interpreter status and asking the interpreter's questions one at a time with multiple choice plus a free-text "Other" option; output path optional, defaulting to the derived system name
