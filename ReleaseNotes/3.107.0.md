`cratis render` can now render a Screenplay model to a Java/Spring application on Axon Framework, as an experimental second target next to the default Cratis target.

## Added

- Added `cratis render --target axon` (experimental). It renders a model to a Java/Spring application on Axon Framework, using the bundled `Cratis.Stage.Rendering.Axon` renderer. `cratis` stays the default target. Axon output carries one experimental warning (`CLI-RENDER-029`), renderer warnings and refusals stay visible, and errors block publication. (#476)
- For Axon, `--project-name` sets the Java artifact name and `--root-namespace` sets the Java package. `--file-header`, scoped rendering, `--force`, drift detection and `--check` behave as they do for the Cratis target. Reducer rendering input, migration requests, `--package-set` and `--strict` do not apply to Java output; they are ignored with a `CLI-RENDER-030` warning. (#476)
- Each target has its own admitted Screenplay version range, so a model newer than the selected target supports is refused with `CLI-RENDER-004` before anything is written. (#476)
