## Added

- `cratis screenplay desktop install|status|update|uninstall` manage the Screenplay MCP server in Claude Desktop and ChatGPT Desktop as regular subcommands, with their own help, shell completion and `llm-context` entries. `--model-root` is offered only by `install` and `update`. (#240)

## Changed

- `cratis screenplay mcp --help` uses the same help layout as every other command and writes it to standard output; protocol runs still keep standard output for JSON-RPC and start no update checks. `cratis screenplay mcp` now rejects a blank `--project-root` or `--project-root-env` value.
- `cratis screenplay mcp install|status|update|uninstall` is deprecated and runs the matching `cratis screenplay desktop` command after a notice on standard error.
- `cratis new --help` describes the reserved `list` template value and the wizard.

## Fixed

- Shell completion no longer lists every subcommand of a command group twice, and no longer offers the global output options for `cratis screenplay mcp`.
