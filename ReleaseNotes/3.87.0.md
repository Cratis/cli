## Added

- `cratis release-notes` shows the release notes of the CLI in the terminal: `--since <version>` lists every release after a version, `--version <version>` shows one, and `-o json` returns them for scripts. Notes for every earlier release ship inside the CLI, so it works offline. See [Release notes](https://github.com/Cratis/cli/blob/main/Documentation/reference/release-notes.md). (#153)
- After `cratis update`, the CLI shows the notes of every release you skipped; when there are several it asks before opening them. (#153)
