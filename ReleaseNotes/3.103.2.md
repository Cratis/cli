## Added
- A specification that plans a model whose concept validation message is a `$strings` key and that has `.en.strings` and `.nb.strings` files next to it. It fails without the fix.

## Fixed
- `cratis render` now passes the model's companion `<base>.<locale>.strings` files to the renderer. Without them Stage refused every `$strings.<key>` validation message with `STAGE-ESM-002` (a concept) or `STAGE-ESM-011` (a specification that expects the message), so a localized model could not be rendered. The default locale is `en` when a file for it exists, otherwise the first locale in ordinal order.
