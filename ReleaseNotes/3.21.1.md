## Changed

- Bundle Screenplay 4.45.0 (Screenplay, MCP and canonical corpus), which adds the `then no readmodel <ReadModel> for <key>` assertion; models that use it compile to ESM v5, which ESM consumers must admit explicitly.

## Fixed

- `cratis screenplay generate` now names the declared enumeration member, including a `[Flags]` zero member, when a scenario asserts it, so generated documents no longer fail with SP0034 ("not a declared member of enum"). A scenario value the document cannot state is left out and reported as warning `SP0039`, and events seeded through a command scenario's event scenario are generated as `given` events. The CLI now bundles Arc's Screenplay generation 22.40.2. (#172)
