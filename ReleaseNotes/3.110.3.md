## Changed

- The CLI bundles the Axon renderer 0.8.0 for rendering Kotlin and Java applications.

## Fixed

- `cratis render` now publishes wrapper scripts such as `mvnw` and `gradlew` as executable, so `./mvnw` and `./gradlew` run straight after rendering instead of exiting with code 126. Re-rendering over a wrapper that lost its execute bit restores it (#490)
