## Added

- `cratis chronicle observers list` and `cratis chronicle observers show` now show when an observer's running state last changed, so a recently disconnected observer can be told apart from one that has been disconnected for a long time. The table and plain output show a `StateChangedAt` value (`-` when the server does not report one), and JSON output includes `runningStateChangedAt` as an ISO 8601 UTC timestamp when it is known. (#77)
