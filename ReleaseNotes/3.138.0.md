## Added

- `cratis run` accepts `--stage-setting KEY=VALUE`, repeatable, to pass settings to the Stage container. The last value for a key wins, and explicit settings override those the run command supplies itself. Not for secrets. (#567)

## Changed

- Internal restructuring of the `new`, `run` and `extension verify` commands to improve maintainability, with no change in behavior. (part of #572)

## Fixed

- A cancellation in the Direct MCP bridge that arrives while the request is completing no longer fails. (#537)
