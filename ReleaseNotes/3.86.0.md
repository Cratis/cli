## Changed

- Bundles Stage 4.177.1 (from 4.174.0) and Screenplay 4.226.0 (from 4.216.0); `cratis run` starts `cratis/stage:4.177.1` by default, and `cratis render` plans with the same renderer. `cratis render` now admits ESM v29 and v30 models. The renderer takes running totals that start with a zero add or may be absent, running totals that add a concept into a number or into another concept, projections keyed by an event property that read the event source identity, joins inside children, events a state-view slice declares, and commands that append to several event sources; a product operand of a running total is still refused with STAGE-ESM-050 and published events and Translate slices are still refused. All five Acme Commerce domains (Catalog, Storefront, Sales, Purchasing, Warehouse) render with these: the generated application builds with 0 warnings and its 447 generated specifications pass.
