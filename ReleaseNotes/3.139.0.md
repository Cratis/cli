The builder images now come with Studio's releases, and the CLI keeps them current the same way it keeps the Stage image current.

## Changed

- `cratis build run --docker` picks the builder image for the target: `cratis/builder`, or `cratis/studio-axon-builder` with `--target axon`. It runs the newest version already pulled, or pulls the latest released version when none is. `--image` with a repository and no tag is resolved the same way.
- After a command, the CLI tells you when a newer version of a builder image you have is released, and `cratis update` pulls it, as it does for the Stage image.

## Removed

- The CLI no longer builds or publishes a builder image; the images are versioned with and released by Studio.
