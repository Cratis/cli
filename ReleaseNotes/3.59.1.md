## Security

- The Chronicle workbench's terminal UI library, SharpConsoleUI, moves to 2.7.0, which no longer depends on SixLabors.ImageSharp. The five ImageSharp advisories (GHSA-gwg2-r3hj-4w44, GHSA-j3p4-wp97-rph4, GHSA-j9gm-c75j-xc9q, GHSA-jjfr-hcj7-qf5w, GHSA-wmxv-xphr-5c9g) no longer apply, and their NuGet audit suppressions are removed, so a future advisory in the dependency graph fails the build again. (#277)
