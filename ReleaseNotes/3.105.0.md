## Added

- `cratis run`, `cratis render` and `cratis screenplay validate` admit `when` and `otherwise` alternatives on `on change`, so a board can run a different command for each column a card is moved to, with the card bound to the command's inputs (`with talkId from item.talkId`).

## Changed

- The CLI bundles Screenplay 4.251.0 and the Stage 4.205.0 container, which runs a component's `on change` for the item the user changed and drops the Theme headline above the topbar theme toggle.
