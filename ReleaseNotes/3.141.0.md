## Added

- `cratis render --target cratis` maps compiler diagnostics and debugger locations for inline `.play` bodies back to the authored `.play` file and line, using C# `#line` directives (part of #505)

## Changed

- The CLI's Chronicle integration specs use Chronicle's published xUnit v3 integration harness instead of a copied fixture, and the integration-only MongoDB.Driver dependency moves to 3.13.0 (#459)

## Fixed

- `cratis ai update` restores missing Cratis-managed files, adapter links and MCP entries recorded in the manifest instead of refusing with exit code 5, so it works in a fresh clone without recreating gitignored adapters by hand (#631)
