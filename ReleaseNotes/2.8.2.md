## Added

- `--debug` now prints the resolved event store and namespace together with the source each value came from (option, context, or built-in default) (#75)

## Fixed

- An explicit `-n Default` (or `-e default`) is now honored literally instead of being treated as "no value given" and silently falling back to the active context's namespace or event store; only an omitted option falls back to the context, then the built-in default (#75)
