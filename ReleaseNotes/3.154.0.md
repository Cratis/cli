`cratis affected` bounds the coverage runs per test project and retries a failed run once.

## Added

- Add `maxAttributionGroups` to `.cratis/affected.json`, which bounds the coverage runs of a test project by letting neighboring namespaces share a run, so a project with hundreds of namespaces builds its map in bounded time (part of Cratis/Workflows#268).

## Fixed

- Fix one flaky spec failing a whole project's coverage map in a merge run; a failed coverage run is now run once more before it counts.
