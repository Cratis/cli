## Changed

- `cratis render` and other commands exit with `10` (`unexpected_error`) on an unexpected failure instead of `-1`; scripts that matched `-1` must match `10`. (#469)

## Fixed

- `cratis render` reports an unexpected renderer failure as `CLI-RENDER-027` and exits with the new code `10` (`unexpected_error`) instead of printing a stack trace and exiting with `-1`; add `--debug` to see the trace. (#469)
