## Fixed

- `cratis screenplay baseline check` and `cratis render`'s release-baseline warnings for PATH input no longer refuse a model root whose `.screenplay` folder has mode `0755`, which is what a git checkout creates. They previously failed with `MetadataPermissions` in fresh clones and CI. Folders that are group- or other-writable are still refused. (#360)
