## Added

- `cratis direct mcp` bridges stdio MCP clients to Direct's remote MCP endpoint using stored Direct credentials. It pins the origin and tenant, keeps stdout limited to JSON-RPC and refreshes a rejected access token once. (part of #206)
- `cratis direct mcp install`, `status` and `uninstall` manage tenant-pinned stdio registrations for Claude Code, Codex, Copilot in VS Code, Cursor and OpenCode in user or project scope. Conflict-safe ownership preserves unrelated configuration, backs up existing files before changing them, keeps existing file ACLs and permissions, rejects overlapping or stale updates and supports dry runs and backup-based recovery of interrupted updates. (part of #206)
