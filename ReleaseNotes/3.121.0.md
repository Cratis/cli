## Added

- `cratis direct setup` connects your AI tools to Direct in one step. It detects the installed MCP clients, signs you in if needed, and registers the Direct MCP server with each of them. `--client` limits the clients and `--dry-run` shows the plan without writing anything. (part of #206)
- `cratis direct mcp install` and `cratis direct setup` can register Direct with pi, in user or project scope. They honor `PI_CODING_AGENT_DIR` and preserve any servers and settings they did not write. (part of #206)
- `cratis direct login --token` and `cratis direct setup --token` sign in with a Direct personal access token instead of the browser flow. The token is read from standard input or `DIRECT_TOKEN` and kept in the operating system's secret store. The token decides the organization, so `--tenant` cannot be combined with it. When Direct rejects the token, the CLI tells you to create a new one instead of trying to refresh it. (part of #206)
