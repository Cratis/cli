## Changed

- Bundles Stage 4.186.0 (from 4.178.2); `cratis run` starts `cratis/stage:4.186.0` by default, and `cratis render` plans with the same renderer. A rendered command form presents an enumeration as a choice, a record as a group of its members and a collection as a list, and a form that populates via a query starts from what the query answered; a property binding or data declaration anywhere on a page (the basket count in a shell's topbar) runs and follows a command (Stage#610, Stage#613).
