## Changed

- Bundles Stage 4.174.0 (from 4.167.1); `cratis run` starts `cratis/stage:4.174.0` by default, and `cratis render` plans with the same renderer. The renderer now renders models whose generated C# names collide (a command property named like its command, a query named like its read model or a property of it) by escaping the colliding member with a trailing `_` and reporting it as STAGE-ESM-050, instead of refusing them with STAGE-ESM-012. It also renders read models with composite keys, scalar absence assertions (`then no <ReadModel> <key>`), per-run projections with optional scalar properties, per-production event source and stream overrides, and live (`observable`) queries that push updates to the generated frontend.
