## Summary

The CLI now bundles Stage 4.208.0 and Screenplay 4.254.0. Generated specifications from `cratis render` execute authored C# bodies and named rules instead of skipping them, and default-mode rendering degrades gracefully in more cases.

## Changed

- The CLI bundles Stage 4.208.0 and Screenplay 4.254.0. Generated specifications now run inline and file named rules, policies, reducers, command handlers and deterministic reaction bodies, so those slices are verified instead of skipped. In default mode, `cratis render` now renders a read model without a projection as an empty read model, and omits `$eventContext` projection mappings with a warning instead of refusing. See the [Stage 4.208.0 release](https://github.com/Cratis/Stage/releases/tag/v4.208.0) for the full list (#495)
- `cratis run` uses the `cratis/stage:4.208.0` image by default (#495)
