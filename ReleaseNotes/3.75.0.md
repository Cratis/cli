`cratis run` now runs Screenplay models with composite read-model keys (ESM v27), and the CLI bundles Stage 4.137.0 and Screenplay 4.204.0.

## Changed

- Bundles Stage 4.137.0: `cratis run` starts `cratis/stage:4.137.0` by default, and its default `semantic` engine runs ESM v27 models with composite read-model keys. The `eventmodel` engine refuses them. (#386)
- The CLI's Screenplay compiler (`cratis screenplay`, `cratis render` and the Screenplay MCP server) is now Screenplay 4.204.0, which reads ESM v27. (#386)
- `cratis render` admits ESM v1 through v27. Stage 4.137.0 does not render composite read-model keys yet: read models and projections keyed by several parts report `STAGE-ESM-048`, single-instance queries by key parts report `STAGE-ESM-047`, and nothing is published. ESM v28 and later are blocked by `CLI-RENDER-004`. See [cratis render](https://github.com/Cratis/cli/blob/main/Documentation/reference/screenplay.md). (#386)
- Generated applications now reference Arc 22.109.0 and Chronicle 19.71.0. (#386)
