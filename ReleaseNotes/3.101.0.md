`cratis render` can now stamp your own copyright header on generated code, and renders with Stage 4.198.0.

## Added

- `cratis render --file-header <LINE>` (repeatable; `\n` separates lines in one value) and `--file-header-file <FILE>` put a header comment at the top of every generated C#, TypeScript and JavaScript file. `{year}` is replaced with the current year. Without either option, generated files have no header.

## Changed

- `cratis render` and `cratis run` use Stage 4.198.0 and Screenplay 4.241.0. Generated C# uses short type names with `using` directives instead of fully qualified `global::` names, generated files no longer carry a Cratis copyright header, and a new application has a single project: specifications live beside the slices and compile into the application project in Debug builds, with no separate `.Specs` project.
- `cratis render` admits models up to ESM v32.
