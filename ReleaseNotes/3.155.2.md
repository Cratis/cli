## Changed

- `cratis build connect` and `cratis build run` require an HTTPS Studio address for builders, whether it is given as an option, saved or set in the environment, and refuse a remote plain-HTTP address; if you use one, connect again with the Studio's `https://` address. Plain HTTP is still accepted for `localhost` and literal loopback addresses during local development (part of #677)

## Security

- Builder registration and authenticated builder requests to Studio no longer follow redirects, so the builder credential is only sent to the configured Studio address (part of #677)
- Agents, generators, verification commands and MCP servers started by `cratis build run` no longer inherit `CRATIS_BUILDER_TOKEN` or `CRATIS_STUDIO_MCP_SECRET`; build images need an updated CLI for processes inside the container to get the same protection (part of #677)
- Docker probes now run without builder credentials or host input, and the Linux credential helper receives only the intended secret through standard input rather than inheriting builder credentials (part of #677)
