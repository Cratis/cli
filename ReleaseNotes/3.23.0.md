## Added

- `cratis view` opens a .NET application as an event model in the browser. Run it in the folder of a `.csproj`: it serves the read-only event model explorer Arc ships on a local web server and opens a browser window on it
- The documents shown are the Screenplay documents embedded in the project's built output assembly (Debug by default) and the assemblies it references; when there are none, or the project has not been built, they are generated from the project's source in memory
- `--configuration`, `--framework`, `--port`, `--from-source` and `--no-browser` options for `cratis view`
