## Added

- `cratis screenplay conform <MODEL_ROOT>` checks that hand-written code still matches an authored Screenplay model: it extracts a model from the code with the same source adapters as `cratis screenplay generate`, without writing anything, and compares it with the model using Screenplay's own comparison (#259)
- Code elements missing from the model and event or member shape mismatches are reported as blocking drift; model elements not yet realized in code are reported as informational, since a model may legitimately be ahead of the code (#259)
- `conform` exits 0 when the code conforms, 1 on blocking drift and 2 when the check could not run or could not compare everything, and `-o json` gives machine-readable findings for CI (#259)

## Changed

- The CLI bundles Screenplay 4.127.0 and reads executable models up to ESM v9; `validate` and the Screenplay MCP server admit v9 models (#302)
- `cratis render` refuses ESM v9 models with `CLI-RENDER-004` until Stage can render public events (#302)
