## Added

- `cratis ai install` and `cratis ai update` register every MCP server whose profile is selected (for example `cratis/playwright` registers `npx -y @playwright/mcp@0.0.83 --headless --isolated`) in Claude Code, Copilot, Cursor, Codex and OpenCode, and remove it when the profile is deselected or on `cratis ai uninstall`. Entries you registered yourself are left untouched and reported as a conflict, with how to resolve it (rename or remove your entry, or set `mcpServers.<id>.enabled` to `false` in `.cratis/ai.json`). A selected server whose descriptor can't be used (unsupported transport, incomplete entry, invalid or duplicate id, or an unknown descriptor schema major version) is skipped with a message instead of failing the install. Pi keeps registering only Screenplay through its native extension and reports other servers as unsupported. (#410)
