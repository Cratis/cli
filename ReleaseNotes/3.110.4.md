The CLI now connects to a Chronicle kernel running without TLS. With `disableTls=true` in the server string it uses cleartext HTTP/2 instead of failing the TLS handshake.

## Changed

- Uses Cratis.Chronicle.Connections and Cratis.Chronicle.Contracts 19.113.2.

## Fixed

- `cratis chronicle` commands work against a kernel started with `tls.enabled=false` when the server string has `disableTls=true`. Combine it with `auth=none` or `apiKey=`; client credentials still need TLS, and the CLI says so instead of failing the token request. (Cratis/Chronicle#5443)
