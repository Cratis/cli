A model with extensions now runs with `cratis run` after its settings and secrets are set with `cratis config`. Extensions are admitted against `screenplay.lock` and the project's allow-list before anything starts, and secret values never appear on a command line, in output or in a file that is committed.

## Added

- `cratis config --requires <model>` lists everything a model needs from the selected environment - identity provider keys, named secrets (`secrets.<Name>`) and the settings of its extensions (`systems.<System>.<setting>`) - with whether each is set. It never prints a value, and exits with `5` while a key is missing or an extension is not restored. (#577)
- `cratis run` admits a model's extensions before starting Docker: each must be pinned in `screenplay.lock` and its publisher and reference allowed in `.cratis/extensions.json`, otherwise nothing starts (exit `5`). Contracts are restored from the lock into the digest-keyed cache, and the Stage keeps pulled packages by digest in a cache that survives runs. (#577)
- `cratis run` hands the Stage the extension settings as `systems__<System>__<setting>` configuration, named secrets mapped to the settings that use them, registry credentials, the allow-list and the signing keys of the locked publishers. The Stage starts each backend in its tier when it is first needed. (#577)
- Documentation for extension settings, named secrets, registry credentials and allow-lists in the [environments](https://github.com/Cratis/cli/blob/main/Documentation/environments/index.md#extension-settings-and-secrets) and [run](https://github.com/Cratis/cli/blob/main/Documentation/reference/run.md#extensions) pages, linked with the Screenplay and Stage documentation. (#577)

## Changed

- `cratis config set` always stores a key under `secrets.` as a secret, with or without `--secret`, and refuses a value given as an argument.
- `cratis config --missing` also lists the named secrets and extension settings a model needs.
- A secret passed to the Stage goes in a file only your user can read, passed with `--env-file` and deleted when the run ends; a secret value that spans several lines, or a registry host with a port, is refused by name.
- `cratis run` on a single `.play` file refuses a model that has extensions: run the folder that holds the model and the lock.
