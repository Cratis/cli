## Changed

- The CLI bundles Stage 4.210.2, which is built against the bundled Screenplay 4.258.0, so the Stage and Screenplay pair matches Cratis Studio again. `cratis run` uses the `cratis/stage:4.210.2` image by default, and generated applications use Arc 22.146.0. (#512)
- `cratis render` now renders ESM v31 policies whose whole condition is `require anonymous` as `[AllowAnonymous]` (information diagnostic `STAGE-ESM-060`) instead of refusing the model; anonymous access combined with other conditions reports `STAGE-ESM-015`.
