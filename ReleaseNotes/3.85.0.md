## Added

- `cratis screenplay conform-namespace <model> --event-store <store> --namespace <namespace>` compares a `.play` model with what a running Chronicle namespace actually holds: registered event types, appended events and their producing commands and reactors, and the namespace's observers. It reads event metadata only (never payloads, event source ids or command values), scans up to `--max-events` (100000 by default) or a `--from`/`--to` range up to the tail captured at the start, and reports a partial scan as such. Output is Screenplay's observation report in human or JSON form; drift exits non-zero only with `--fail-on-drift`. (#200)
