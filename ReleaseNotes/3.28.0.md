## Added

- `cratis screenplay mcp` now finds the model itself. It serves the folder that already holds the project's `.play` files, otherwise `Source/` or `src/`, otherwise a new `Screenplay/` folder at the project root. It also works in a project with no `.cratis/ai.json`.

## Changed

- `cratis ai install` and `cratis ai update` no longer create or require `.cratis/screenplay/`. Only an explicit `mcpServers.screenplay.root` in `.cratis/ai.json` names a model directory, and that directory must exist. A model already in `.cratis/screenplay/` keeps working.
