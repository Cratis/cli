## Added

- `cratis run --sample-data [pack]` seeds a model's user-authored sample data pack into the disposable semantic sandbox, so runtime queries show the pack's rows. Without a pack name the first UI profile's bindings and active pack decide; a named pack overrides both. An unknown pack, or `--engine eventmodel`, is refused before Docker starts. See [Sample data in the sandbox](https://github.com/Cratis/cli/blob/main/Documentation/reference/run.md#sample-data-in-the-sandbox).
- The seeds are ordinary Screenplay seed events derived from the read model's scalar projection mappings, including later update events, so separate price or approval events fill the same row. An authored `seed` for the same id wins. Collection properties stay empty with a warning naming Cratis/Screenplay#1000, and blueprint-only packs, joins, custom keys and non-invertible expressions are reported as warnings. (#429)
