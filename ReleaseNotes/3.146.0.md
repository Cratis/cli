The Cratis CLI signs in to Cratis Direct only through Cratis Identity in the browser. Direct no longer issues personal access tokens, so the CLI no longer accepts one.

## Removed
- `--token` on `cratis direct login` and `cratis direct setup`, and the `DIRECT_TOKEN` environment variable. A login saved earlier as a personal access token stops working with a message to run `cratis direct login`; `cratis direct logout` still removes it.
