## Added

- `cratis run --engine <eventmodel|semantic>` starts the Stage sandbox on the chosen runtime engine. `semantic` runs the Screenplay executable model, enforcing validation, requirements, authorization, conditional production and constraints, and running models with named event sources and streams. Without the option, Stage's default engine runs as before. (#368)

## Fixed

- `cratis run` no longer reports a model as ready when Stage refuses to run it. It waits for Stage's status, lists every refusal issue, stops the container and exits 5. A routed model refused by the default engine (`STAGE-ESM-030`) suggests `--engine semantic`. (#368)
