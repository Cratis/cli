## Added

- `cratis llm-context` now gives every command an `effect` — `read-only`, `local`, `mutating` or `destructive` — and a `requiresConfirmation` flag, so agents and guards can tell observing commands from state-changing ones without keeping their own lists.
- The `cratis llm-context --schema` JSON Schema, the catalog's tips, the generated `CHRONICLE.md` safety notes and a new LLM Context reference page explain both fields and what each value means.
