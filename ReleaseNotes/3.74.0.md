`cratis render` now accepts Screenplay models up to ESM v26, and the CLI bundles Stage 4.135.0.

## Changed

- `cratis render` admits ESM v21 through v26. Stage plans each model and refuses the constructs it cannot render yet with typed `STAGE-ESM-*` diagnostics, so nothing is published for them; for example, models compiled to ESM v22 report `STAGE-ESM-016` with Stage 4.135.0. ESM v27 and later are still blocked by `CLI-RENDER-004`. See [cratis render](https://github.com/Cratis/cli/blob/main/Documentation/reference/screenplay.md). (#384)
- Bundles Stage 4.135.0: `cratis render` uses its renderer and `cratis run` starts `cratis/stage:4.135.0` by default. (#384)
