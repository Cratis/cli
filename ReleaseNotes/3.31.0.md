## Added

- `cratis screenplay generate --authoring-only-constructs` also writes Arc constructs that are not executable yet: operations and the systems they use, event sources and streams with command routes, and `reads` and `require` recovered from `Provide()`. A document using them has no executable model. Providers other than Arc warn with `CLI0014`. (#262)

## Changed

- `cratis screenplay generate` uses Cratis.Arc.Screenplay 22.52.0. Generated Arc models now carry command identifiers, `for` routing, inline events, event metadata, named rules and `when append` specifications. Generated identifiers and command responses produce ESM v7 models, which `cratis render` does not accept yet. (#262)
