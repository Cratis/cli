## Added

- `cratis render` (publish, `--check` and `--scope`) reports Stage's release-baseline warnings when a render would change (`STAGE-BASELINE-001`) or drop (`STAGE-BASELINE-002`) an event revision admitted to the model's release baseline, or when the baseline cannot be read (`STAGE-BASELINE-003`) or checked (`STAGE-BASELINE-004`). The warnings cover the whole application, also for scoped renders, and never change the exit code, the written artifacts or the receipt; keep `cratis screenplay baseline check` as the gate in CI. See [Release-baseline warnings](https://github.com/Cratis/cli/blob/main/Documentation/reference/screenplay.md#release-baseline-warnings). (#356)
- `cratis render --workspace <FILE> --baseline <FILE>` selects the release baseline for workspace input; without it, render uses `.screenplay/release-baseline.json` beside the workspace file. PATH input reads the baseline from the model root's `.screenplay/` folder. (#356)
