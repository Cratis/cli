## Added

- `cratis screenplay validate <path> --scope <Module>[.<Feature>[.<Slice>]]` checks one module, feature or slice and the declarations that directly reference it, with the same selection and exit-code rules as the `screenplay` tool; the whole application's error and warning counts are always reported alongside, in the console and in JSON, and `--scope` combines with `--check` (#274)

## Changed

- The bundled Screenplay compiler and MCP server are now 4.87.0, which adds the `propose-source` authoring tool to `cratis screenplay mcp`; the MCP reference lists it (#285)
