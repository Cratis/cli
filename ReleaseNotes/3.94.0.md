## Changed

- Bundles Stage 4.192.0 (from 4.190.12): `cratis run` starts `cratis/stage:4.192.0` by default and `cratis render` plans with the same renderer. Rendered applications and the live Stage now use React Aria through `@cratis/components` by default; a Screenplay that wants PrimeReact lists it in its ui profile (`packages` → `PrimeReact`). Stage 4.192.0 is built against Scene 4.80.2 and `@cratis/components` 4.34.0 (#445)
- `cratis render` scaffolds a PrimeReact application, with its packages and provider, when the Screenplay's ui profile lists `PrimeReact`, and the React Aria application otherwise; Stage accepts the rendered application in both cases (#445)
