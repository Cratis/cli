## Summary

The CLI bundles Stage 4.92.0. `cratis render` and `cratis run` pick up live and snapshot list queries, `all` projections and readable event-source classes.

## Changed

- The CLI bundles Stage 4.92.0, and `cratis run` starts the matching `cratis/stage:4.92.0` image.
- Observable collection queries render as Arc observable queries that push every change to subscribers, and snapshot collection queries now render instead of being refused, with or without a `by` key and equality filters.
- Screenplay `all` projection blocks whose mappings set event-source identities render as Chronicle `FromAll`; `all` blocks with literal mappings or no mappings are still refused with `STAGE-ESM-017`.
- Event sources with PascalCase names render as `{Name}EventSource` classes with a public constant per stream, and every generated stream reference uses that constant; the stored stream names Chronicle sees are unchanged. A constant that collides with another member or a C# keyword is refused with `STAGE-ESM-012`.
