The CLI now bundles Screenplay 5.1.0 and Stage 4.214.0, so `cratis` accepts models written in the Screenplay 5.x form and renders and runs them with a matching Stage.

## Added

- `cratis --version` reports the bundled Screenplay compiler version next to the CLI version, so you can compare it with `screenplay --version`. (#533)
- `cratis screenplay generate` reports progress while it loads the workspace, prepares resource sources, compiles and generates, instead of staying silent until it finishes. (#507)

## Changed

- The CLI bundles Screenplay 5.1.0 and Screenplay.Generation 0.19.0. Objects and lists in a model must be written as indented blocks; inline JSON values are rejected with `PLAY0833`. (#533)
- The CLI bundles Stage 4.214.0, built on Screenplay 5.1.0, and `cratis run` uses the `cratis/stage:4.214.0` image by default. Models with state machines or workflows (ESM v36) are still refused. (#533)

## Fixed

- A cancelled `cratis screenplay generate` no longer prints one more stage line before stopping. (#534)
- `cratis ai update` keeps rules that apply to several languages, such as Elixir rules in a mixed-language glob, when it filters the corpus by the selected languages. (#526)
