# Cratis CLI v3.0.0 - Chronicle 18 Upgrade

## Breaking Changes

### Chronicle 18 Upgrade

This release upgrades the CLI to work with **Chronicle 18**, which includes significant changes to the Chronicle API:

- **Package version updates**: `Cratis.Chronicle.Connections` and `Cratis.Chronicle.Contracts` upgraded from 16.x to 18.1.0
- **Prologue package updates**: All Prologue packages upgraded from 1.1.0 to 2.0.0
- **Screenplay package updates**: `Cratis.Screenplay` upgraded from 1.6.4 to 4.12.1
- **Stage rendering updates**: `Cratis.Stage.Contracts` and `Cratis.Stage.Rendering.Cratis` upgraded to 3.11.0

### What this means for users

- Applications using the CLI must be compatible with Chronicle 18
- Existing Chronicle event stores may need to be upgraded to Chronicle 18
- The CLI's terminal workflows for inspecting and diagnosing Chronicle remain unchanged

## New Features

### Enhanced Screenplay Generation

The Screenplay generation commands now provide more detailed source compatibility provenance:

- Support tier reporting (`Canonical`, `SourceReviewed`, `RecognizedWithLoss`, `Unknown`, `Unsupported`)
- Recognition status and semantic conformance reporting
- Lowering fidelity tracking for behavior that cannot be exactly represented

### Improved Diagnostics

- Better error messages for unprojected projects
- More detailed compatibility reports for Marten and Critter Stack providers
- Enhanced validation for multi-targeted projects

## Upgrade Path

### From v2.x to v3.0.0

1. Ensure your Chronicle server is running version 18.x
2. Update your application projects to be compatible with Chronicle 18
3. Run `dotnet tool update Cratis.Cli` to get the latest CLI version

### Rollback

If you need to rollback to a previous version:

```bash
dotnet tool install Cratis.Cli --version 2.9.0 --global
```

## Known Limitations

- Arc provider continues to use its existing adapter compatibility contract rather than the Critter Stack support-tier matrix
- `--modules-from-namespace-roots` reports `CLI0014` warning with Marten or Critter Stack (not applied)
- Marten and Critter Stack source generation remains in preview
