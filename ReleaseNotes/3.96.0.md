## Changed

- Bundles Stage 4.196.0 (from 4.192.0): `cratis run` starts `cratis/stage:4.196.0` by default and `cratis render` plans with the same renderer, matching the Stage version Studio uses. Stage 4.196.0 is built against Screenplay 4.240.2 (unchanged). Rendered authorization policies are now named after the modeled policy (`{Name}Policy`, registered as `{Name}`) instead of carrying hashes, a validation message that uses `$strings` without a strings catalog is refused with `STAGE-ESM-019`, and the semantic specification runner runs Translate slices and many projection shapes it used to report as unsupported (#446)
