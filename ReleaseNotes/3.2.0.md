## What this does

The `cratis ai` command group ships in the CLI but had no documentation. This adds:

- **`Documentation/ai/index.md`** (registered in the docs toc) — the `.cratis/ai.json` configuration format, the `install` / `update` / `status` / `uninstall` commands with their options, conflict semantics, what gets installed where, and the error table. Documented against the current implementation in `Source/Cli/Commands/Ai/`.
- **README section** — a \u201cCratis AI\u201d section with the command overview and the templates flow: the Cratis `dotnet new` templates ship `.cratis/ai.json` preconfigured, so a scaffolded project only needs `cratis ai update` (matching the reminder those templates now print after creation, pointing at https://cratis.io/cli).

Docs-only plus the package README, which is packed content — hence the minor label per the publish paths policy.
