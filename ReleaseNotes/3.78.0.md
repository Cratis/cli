## Changed

- Bundles Stage 4.146.0 and Screenplay 4.212.2; `cratis run` starts `cratis/stage:4.146.0` by default (#395)
- A model `cratis render` refuses now lists every independent refusal at once, so fixing it no longer reveals new refusals one render at a time (#395)
- `cratis run` on the semantic engine refuses only the commands and queries that reach a reducer or code-bodied validation, with `STAGE-IMPL-003`, and runs the rest of the model (#395)
- Rendered applications pin Arc 22.112.1 and Chronicle 19.78.0 (#395)
