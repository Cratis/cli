Screenplay models can now reference extension packages and the CLI resolves, pins, moves and copies them. The new `cratis extension` group is where the other extension commands will join.

## Added

- `cratis extension restore` fills the extension cache from `screenplay.lock`. A reference the lock does not pin is resolved to the newest release in its range and pinned with its version, digest, contract hash and publisher. `--locked` fails on a missing or mismatched entry and never changes the lock. (part of #578)
- `cratis extension update [SYSTEM]` moves one system's extension, or every referenced extension, to the newest release in its range. It reports what each new contract adds, removes or changes, and every use in the model the new contract no longer offers, before the lock is written. `--dry-run` writes nothing; `--allow-incompatible` writes anyway.
- `cratis extension vendor <DESTINATION>` copies every locked package, with its signature, to a folder or an `oci://host/prefix` registry for air-gapped deployments. `cratis extension restore --source <DESTINATION>` then restores from the copy without reaching the original registries.
- Packages come from catalog short names (`"cratis/stripe"`), full OCI references and frontend-only package references. Private registries authenticate with credentials stored through `cratis config` under `extensions.registry.<host>.token` (or `username` and `password`); no command prints a credential.
- Trust: a package must be signed, its signature must be valid for its digest, and its publisher must be on the project's allow-list in `.cratis/extensions.json`. A first-time publisher is confirmed interactively and recorded; a non-interactive run fails instead. A publisher whose key changed is never offered for trust.
- Reference pages for the [extension commands](https://github.com/Cratis/cli/blob/main/Documentation/reference/extension.md), linked with the Screenplay [extension contracts and lock reference](https://github.com/Cratis/Screenplay/blob/main/Documentation/screenplay/extension-contracts.md).

## Changed

- The CLI bundles Screenplay 6.22.0, which adds the extension contracts and the lock.
