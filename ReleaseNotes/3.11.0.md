## Added

- Run the Screenplay MCP server with `cratis screenplay mcp`, bundled into the Cratis CLI with no separate Screenplay tool installation or startup download.
- Configure Screenplay MCP automatically when `cratis ai install` or `cratis ai update` selects the Screenplay profile, including profiles that compose it. Supported native configurations cover Claude Code, VS Code/Copilot, Cursor, OpenCode, Codex and Pi.
- Choose a project-local model directory or disable registration in `.cratis/ai.json`; dry-run and status report the planned and installed registrations.

## Changed

- Preserve existing MCP servers, comments and unrelated settings during install, update and uninstall. User-owned or modified Screenplay entries are reported as conflicts rather than overwritten.
- Keep MCP standard output exclusively JSON-RPC and suppress CLI update checks during a protocol session.
