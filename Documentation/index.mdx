## Your first inspection

[Getting started](getting-started/index.mdx) is the installation and first-inspection tutorial.
Choose Homebrew, a native release, or the .NET tool, select an authorized Chronicle
server, then inspect one event store and namespace. You'll learn which settings
are local and what a completed diagnostic report does—and doesn't—prove.

## Where the CLI fits

The CLI is the terminal inspection and diagnosis path in the Cratis Platform.
[Chronicle Workbench](/chronicle/workbench/) provides the bundled browser surface
for authorized runtime inspection and preview of supported projection behavior.
The CLI's [Arc group](arc/index.md) instead connects to an application's HTTP
introspection endpoints. A Chronicle context does not select that application.

Other command groups have their own documentation. Their presence does not
establish another product's maturity, compatibility, or availability.

## Before changing state

:::caution[Inspection is not authority]
Confirm the server, event store, namespace, exact observer or partition, and
expected effects before recovery. A successful inspection is not permission to
retry, clear quarantine, replay, or execute a recommendation.
:::

Connection strings and context files can contain credentials. Keep them out of
source, public issues, shared logs, and assistant prompts. Ordinary output is not
an unversioned stable machine contract; use the exact CLI version and documented
command scope. Command availability does not establish support, an SLA,
reliability, security, compatibility, or production suitability.
